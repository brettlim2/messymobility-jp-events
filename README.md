# MessyMobility · Japan Events (public demo)

Cached static dashboard for **Fuji TV × Odaiba** and **CAPCOM × Tokyo Game Show**.

**Live:** https://brettlim2.github.io/messymobility-jp-events/

Built from the Factori Japan mobility panel (Sep 16–23 2026) plus curated social corpora for Odaiba Drone Show and TGS. Panel estimates, not census.

```bash
npm install
npm run dev    # http://localhost:5178
npm run build  # static dist/ with public/data cubes
```
